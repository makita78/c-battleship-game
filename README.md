# c-battleship-game
This repository contains a Battleship game implemented in C as part of my undergraduate coursework. The project was developed incrementally, beginning with a 1D version and extending to a 2D game with map visualization and random ship placement. It demonstrates the use of data structures, functions, arrays, user interaction, and game logic.
This project was originally developed as part of university coursework and was later uploaded to GitHub for portfolio and application purposes.
